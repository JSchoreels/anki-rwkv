# Fast Good/Easy prediction (SM120): result

**What answer time means.** The answer time is the whole time on the card, front and back together: from the moment the question is shown to the moment a grade button is pressed, capped at the preset's maximum answer seconds. The "Show answer" moment is not stored, so front-only and back-only times cannot be computed. Every "within S s" below means answered within S s, reading the back included.

Scoring only (no training): the answer-time heads of the time heads for the family (SM117) and of the time heads for the new candidates (SM119) on their frozen models, the 732 set (723 users, show-time inputs, leak-free, the SM117 time-labelled test reviews). Pre-registered in `design.md`. Reliable = ECE (20 equal-mass bins) below 0.01 and LogLoss below every baseline with the 95% CI (2,000 user bootstraps, seed 0, review-weighted) below zero. Deltas are model minus baseline. S counts only below the user's own maximum answer seconds.
