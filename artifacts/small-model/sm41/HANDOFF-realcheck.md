## What runs (CPU only)

- **Runner:** `realcheck/run-realcheck.sh`, launched hidden via WMI (Windows pid 34552; the bash pid is logged in
  `realcheck/runner.log`).
- **Jobs:** one job per user (117 users, 304 splits, largest first, `realcheck/jobs.txt`).
  - Each job runs `scripts/sm41_realcheck.py run`: the released small model teacher-forced on the user's real 60-day
    windows (the engine's `tf` lane with hooks).
  - Output: `realcheck/logs/<user>-<split>.npz`, about 1-3 MB each; not committed, regenerated by the runner. Job
    logs: `realcheck/joblogs/<user>.log`.
- **Load:**
  - 4 processes, 1 thread each, below-normal priority, about 600 MB each. The beta = 3 confirmation finished at
    14:34, so its 2 slots were added at 14:35.
  - Speed: about 115 real reviews/s per process in the engine, plus the warm-up (40-50 s per large user).
  - Estimate: about 6.5-7 process-hours.
  - quiet.json holds inside every job. The next window is 20:00-01:00; the run should be done well before it.
- **At the end, the runner:**
  - runs `sm41_realcheck.py analyze`, which writes `realcheck/realcheck-tables.md`, `realcheck/realcheck.json`,
    `realcheck/per-user-point3.csv`, `realcheck/per-user-point4.csv`, `realcheck/splits.csv` and
    `realcheck/analyze.out` (the tables plus the run cost);
  - writes "done" in `realcheck/runner.log`.
- **Resumable.**
  - A user's split is skipped when its `.npz` exists. Per-user lock dirs in `realcheck/locks/` keep the two pools
    apart.
  - If the runner died (no "done" in `runner.log`, no `sm41_realcheck.py run` python process), delete
    `realcheck/locks/`, then relaunch:
  ```
  $si = New-CimInstance -ClassName Win32_ProcessStartup -ClientOnly -Property @{ShowWindow=[uint16]0}; Invoke-CimMethod -ClassName Win32_Process -MethodName Create -Arguments @{CommandLine='"C:\Program Files\Git\usr\bin\bash.exe" -c "export PATH=/usr/bin:/mingw64/bin:$PATH; bash /c/Users/jonat/workspace/wt/sm41/artifacts/small-model/sm41/realcheck/run-realcheck.sh >> /c/Users/jonat/workspace/wt/sm41/artifacts/small-model/sm41/realcheck/runner.out 2>&1"'; ProcessStartupInformation=$si}
  ```
