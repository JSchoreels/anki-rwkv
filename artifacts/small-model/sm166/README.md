## Answer-time vectors

`time_vectors.py` uses PyTorch on the CPU. It reads the model code from `wt/fork-rc-export`, read only, and writes
nothing there. It follows the recipe of the time heads for the family (SM117) packaging step:

- `master.pth` equals `weights.f32.bin` bit for bit;
- the show-time batch of each synthetic user equals the package's own vectors;
- it computes the frozen inputs, explicit features and logits;
- the rows that the fork's own fixture (`rslib/src/rwkv/testdata/*-time-vectors.json.gz`) holds equal the fixture,
  for all six models, at f32 and int8 (largest difference 0).
